# DOM Manipulation Basics

## Project
Student Management Dashboard

## Features

- Add Student
- Delete Student
- Search Student
- Dynamic Student Count
- Real-time DOM Updates

## DOM Concepts Used

- getElementById()
- createElement()
- appendChild()
- innerHTML
- textContent
- addEventListener()
- filter()
- Dynamic Rendering

## Learning Outcome

Learned how to manipulate the DOM dynamically using JavaScript by creating, updating, searching, and deleting elements in a real-world application.
