# ES6+ Advanced - Order Management System

## Description
A real-world order management system using ES6+ features.

## Features
- Create order using multiple products
- Calculate total price
- Display order dynamically

## Concepts Used
- Arrow Functions
- Destructuring
- Spread Operator
- Rest Operator
- Modules (import/export)
- Arrays & Objects

## Learning Outcome
Learned how to combine ES6 features to build real-world applications with modular and clean code.
