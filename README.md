# 📚 React Class Components - Library Management System

## Description

A Library Management Dashboard built entirely using React Class Components.

---

## Features

- Dashboard Statistics
- Add Book
- Search Book
- Borrow Book
- Return Book
- Delete Book
- View Book Details
- Responsive Layout

---

## React Concepts Covered

- Class Components
- Constructor
- State
- Props
- setState()
- Event Handling
- Conditional Rendering
- Dynamic Rendering
- Component Composition
- Component Communication

---

## Project Structure

```text
src
 ├── components
 ├── data
 ├── App.jsx
 ├── App.css
 └── main.jsx
```

---

## Learning Outcome

Learned how to build a complete React application using Class Components, state management, reusable components, props, event handling, and dynamic rendering.
